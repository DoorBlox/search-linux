# Still Browser — Linux port

A fast, quiet Linux browser inspired by [Search](https://github.com/driceroland/Search) and Arc's organization of tabs and Spaces. Native GTK4/WebKitGTK shell, built for ChromeOS Crostini (Debian 13).

**Status: early development.** The original Search source is MIT licensed (copyright Office Commun). Still is an independent port with a separate name and identity. Feature parity and Chrome extension compatibility are work in progress; do not assume either is complete.

Development instructions and checkpoints live in `AGENTS.md`, `CHATGPT_HANDOFF.md`, `docs/PROGRESS.md`, and `plans/SEARCH_LINUX_EXECUTION.md`.
